# Описание проекта

## Задача

Mesh2D строит структурированную четырёхугольную сетку по параметрической геометрии для подготовки плоских конечно-объёмных расчётов. Исследовательская часть проекта — предсказание положения внутренних узлов по форме границ с помощью машинного обучения.

## Вход и результат

На вход подаётся JSON-файл с геометрией и числом ячеек. Для четырёхстороннего блока доступны кривые Безье, сгущение и имена границ. Пользователь выбирает метод и формат через CLI. Результат — файл SU2, VTK или OpenFOAM `blockMeshDict`, JSON-отчёт о локальном качестве и визуализация по запросу.

| Геометрия | Методы | Особенности |
| --- | --- | --- |
| Четырёхсторонний блок | `ai`, `tfi` | Прямые стороны или квадратичные кривые Безье |
| Круг и пятиконечная звезда | `radial` | Геометрическое отображение квадратной решётки |
| Область между эллипсами | `radial` | Допускаются разные центры, внутренняя область пустая |
| Область между прямоугольником и эллипсом | `radial` | Режим `inner_shape: quadrilateral` |

## Архитектура

| Модуль | Назначение |
| --- | --- |
| `mesh2d/cli.py` | Аргументы, чтение JSON, экспорт, обработка ошибок |
| `mesh2d/core.py` | Выбор метода, четырёхсторонняя геометрия, качество |
| `mesh2d/model.py` | Обучение и применение линейной модели |
| `mesh2d/shapes.py` | Круг и звезда |
| `mesh2d/ellipses.py` | Область с отверстием |
| `mesh2d/export.py` | Связность, граничные группы, запись сетки |
| `mesh2d/visualize.py` | Изображения и интерактивный просмотр |

## Экспериментальный метод

При первом вызове `ai` в процессе линейная модель обучается на 96 синтетических граничных профилях. Для приближённых гармонических полей используются 320 итераций дискретного осреднения на решётке 17×17. Веса определяются методом наименьших квадратов и кешируются в памяти. Генератор случайных чисел имеет фиксированный seed.

Модель предсказывает смещения относительно билинейного отображения углов. Поле интерполируется на нужное разрешение, а граничные узлы устанавливаются непосредственно на кривых. Готовая сетка на вход не требуется. Метод `tfi` предоставляет классическое построение для той же геометрии. Преимущество `ai` в скорости или точности CFD не установлено.

## Границы проекта

Решатель физических уравнений, импорт произвольной CAD-геометрии и автоматическое многоблочное разбиение не реализованы. Проверка локальных якобианов не гарантирует отсутствия глобальных пересечений и не заменяет исследование сеточной сходимости. OpenFOAM-экспорт рассчитан на небольшие сетки; поля и граничные условия настраиваются во внешнем расчётном случае.
