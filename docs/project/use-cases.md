# Сценарии использования

## UC-01. Построить и сохранить сетку

**Участник:** пользователь, подготавливающий сетку для плоского расчёта.

**Цель:** получить файл сетки и отчёт о локальном качестве.

**Предусловия:** установлены зависимости, доступна команда `poetry run mesh2d`, подготовлен JSON, имеется право записи в каталог результата.

```sh
poetry run mesh2d examples/channel.json --method ai --format vtk -o out/channel.vtk --plot out/channel.png
```

### Основной поток

1. Пользователь указывает JSON, метод, формат и путь результата; при необходимости — путь изображения.
2. CLI проверяет аргументы и пути, читает JSON.
3. Генератор проверяет параметры геометрии и выбирает алгоритм.
4. Для `ai` при первом вызове в процессе обучается модель и предсказываются смещения; для `tfi` или `radial` применяется геометрический метод.
5. Проверяется качество ячеек и формируется отчёт.
6. Создаётся каталог результата и сохраняется сетка.
7. По запросу сохраняется изображение и открывается интерактивное окно.
8. После завершения визуализации в терминал выводится JSON-отчёт.

**Постусловия успеха:** файл сетки существует, отчёт содержит число ячеек и три показателя качества; изображение сохранено, если указан `--plot`.

### Альтернативные потоки

| Условие | Поведение |
| --- | --- |
| Метод не указан | Используется `ai` |
| Формат не указан | Используется `su2` |
| Круг, звезда или область с отверстием | Требуется `radial`; другой метод отклоняется |
| Нет `--plot` и `--show` | Экспорт и отчёт без визуализации |
| Кольцевая область, SU2/OpenFOAM | Шов объединяется, сохраняются внутренняя и внешняя границы |

### Ошибки

- Ошибки чтения, JSON, обработанные ошибки параметров и записи: сообщение с префиксом `mesh2d:`, код 2.
- Недопустимое качество: отказ до записи сетки.
- Совпадение входного и выходных путей или неподдерживаемое расширение изображения: отказ до генерации.
- Ошибка изображения может возникнуть после сохранения сетки; уже записанный файл автоматически не удаляется.

## UC-02. Сопоставить методы

**Участник:** исследователь сеткопостроения.

1. Выбирает четырёхстороннюю геометрию, например `examples/channel.json`.
2. Запускает `ai` и `tfi`, задавая разные пути результатов.
3. Сопоставляет изображения и отчёты.
4. При необходимости независимо измеряет время и выполняет внешние расчёты.

**Результат:** две сетки для одного описания геометрии. Автоматический бенчмарк и подтверждение превосходства одного метода не реализованы.
